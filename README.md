# 冰河地形工作室 V4.1 — 阿雷奇範例同尺度／大型地景

這是 V4 的後續更新，保留 **同一 3D 工作區內操作地形積木、手繪塑形、邊界高度、側壁實心模型、A4 等高線、ASC 和 GLB 匯出**，並加強場景尺度與網格精度。

## 重點更新

1. **精細地景預設 23 × 18 km**，內部為 461 × 361 個高程採樣點，兩方向網格間距均為 50 m；以阿雷奇冰河參考網站的空間尺度為目標，但 **不是該站的完全相同邊界**。此版本以橫向為 23 km，南北向為 18 km，方便橫式 A4 製圖。
2. 其他場景：18 × 23（長谷方向）、20 × 12、40 × 30、50 × 30、80 × 48、120 × 72、180 × 108 km，亦可另外自行輸入南北範圍。**大型場景仍使用同一採樣點數**，會犧牲局部解析度。
3. **阿雷奇真實地形載入**：約 18 × 23 km、從公開 Terrarium 高程圖磚讀取、拼接 5 × 5 張圖磚，依指定長寬裁切並重採樣。此案例使用與參考網站相同順序的長寬，但不保證地理裁切邊界相同。資料來源是 Mapzen AWS Terrain Tiles，並非參考網站採用的 Copernicus GLO-30 DEM。初次載入需要下載 25 張圖磚，可能受網路、CORS 或供應商狀態影響。
4. 3D 水平比例根據設定的東西及南北長度同步調整，避免長方形場景被固定形狀拉伸。
5. ASC 匯出會重新取樣成方形像元，避免不同長寬比的場景在 QGIS 當中地理比例扭曲。
6. V2 / V3 / V4 舊專案 JSON 支援依固定格網重新採樣後開啟。修改前先備份專案。

## 使用

將 `index.html`、`style.css`、`app.js`、`terrain-core.js` 上傳 GitHub Pages 同一儲存庫根目錄，覆蓋舊檔案。

1. 在「場景尺度」選擇 **阿雷奇範例同尺度｜23 × 18 km（約 50m）**，輸入四角高度，按「依邊界高度建立新地表」。
2. 在中央 3D 工作區選取角峰、冰斗、刃嶺、冰槽等積木，再點擊模型放置；或使用抬升／下切／平滑／整平筆刷。
3. 按「2D 等高線」檢查對應的平面判讀圖。
4. 按「地形模型 GLB」下載立體模型，或以「A4 學生等高線圖 PNG」輸出紙本。
5. 要試真實冰河地表，按「阿雷奇冰河附近」。該資料的地貌、高程與自創地形積木不同，混用後須標示為「真實 DEM＋教學模擬」。

## 效能與精度

- 23 × 18 km 預設：461 × 361（約 16.6 萬個採樣點）；50 m 網格。
- 80 × 48 km：同樣格網，間距約 174 × 133 m。對幾十公尺寬的蛇丘和小鼓丘來說仍可能太粗。
- 這不是自適應多解析度 GIS 引擎。切換場景大小不會增加採樣點數。編輯超大地景時，應另做局部地形工作檔。
- 真實地形圖磚資料經過網格重採樣，不等於現地調查、地質證據或精確地貌分類。立體地形能看到形態，但不能僅靠等高線確定羊背石、鼓丘等成因。
- 目前沒有加入參考網站的 Sentinel-2 衛星影像貼圖；外觀維持教學用的自然色地形。
- 3D 視覺與 GLB 仍需要在實際使用的瀏覽器測試。核心 DEM 網格計算、ASC 匯出及程式語法已測試。
