# 冰河地形等高線編輯器 V1

此為純前端教材製作工具。無須 Google Apps Script 或付費主機，部署到 GitHub Pages 即可使用。建模與成果下載在瀏覽器本機執行；3D 預覽與 GLB 匯出需要載入網路上的 Three.js 套件。

## 1. 上傳／部署

請將**下列四個檔案同時放在同一個 GitHub Pages 儲存庫根目錄**：

- `index.html`
- `style.css`
- `app.js`
- `terrain-core.mjs`

在儲存庫 `Settings → Pages → Deploy from a branch → main / (root)` 啟用網站。網頁網址範例 `https://<帳號>.github.io/<儲存庫>/`。

如果你原本的冰河 AR 網站仍要保留，建議另建儲存庫 `glacier-terrain-editor`，避免覆蓋之前的 `index.html`。

若在電腦上用檔案總管直接雙擊 `index.html`，因瀏覽器 ES module 檔案存取限制，可能無法載入。應使用 GitHub Pages 或本機 HTTP 伺服器（例如在此資料夾執行 `python -m http.server 8000`）。

## 2. 使用方式

1. 按「載入範例」瀏覽虛構地景；正式自行設計請按「建立空白」。
2. 輸入目前繪製高度，如 `1800`。
3. 選「封閉等高線」，在左側畫一個圈，放開滑鼠即建立。
4. 修改高度，如 `1900`，畫一個更小的內圈。持續向內畫高程更高的圈。
5. 選「高程控制點」，在最裡面點一下並設定山頂高度，如 `2200`。
6. 對冰斗或谷底，可以放置**較低高程**的控制點。對稜線可以使用「開放控制線」。
7. 右側地形會在每次完成編輯後重新計算，可用滑鼠拖曳旋轉、滾輪縮放。
8. 若需修改，切換「選取修改」，點選線條或控制點，再修改高度或刪除。
9. 「A4 學生圖 PNG」輸出的是由最終 DEM **重新推算**的等高線，而非直接把手繪控制線列印出來。
10. 「儲存專案」會儲存 JSON，可下次按「開啟專案」繼續。

## 3. 輸出功能

- `glacier-student-A4.png`：橫式 A4 尺寸比例的等高線教學圖。四角特殊圖案僅作為未來 AR 辨識的示意固定視覺特徵，**並非保證能追蹤的 ArUco 標記**；必須用 MindAR 編譯與實機測試。
- `glacier-terrain.glb`：與高程網格對應的 3D 地形。WebAR 使用時仍需依圖框位置校準縮放、軸向與平移。
- `glacier-dem.asc`：ESRI ASCII Grid，160×96 像元、像元大小 100（假設單位公尺）。可直接拖入 QGIS 當 raster，坐標為**虛構的局部公尺坐標**，不是任何真實 CRS。若 QGIS 要求座標系統，請用自訂工程 CRS 避免當成真實地理位置。
- `glacier-heightmap-8bit.png`：相對高程灰階圖，黑＝目前最低高程、白＝最高高程。8-bit PNG 未保存絕對海拔值，不可當作精確 DEM。
- `glacier-terrain-project.json`：完整等高線和點資料，可回頭編輯。

## 4. 地形內插方法與限制

地形採**固定高程線與控制點的離散調和（harmonic）內插**。高程線靠近網格時固定最近網格節點，其他位置用迭代平滑填補。

這個方法能構造連續教學地形，但不等同於 QGIS TIN、克利金或水文流向建模：

- 等高線間的真實坡形無法單憑等高線唯一還原。
- 高程控制線不應交叉或重疊不同高程。近距離控制線可能互相影響，造成局部階梯或尖峰。
- 最外側的地表高度受「左／右側邊界高程」控制；其他邊界沿同一線性坡度假設。
- 冰斗、鼓丘、端磧、蛇丘的**成因**無法單靠外形或等高線辨識，需要額外的地質沉積資訊或題目線索。
- 右側模型的垂直誇大用於觀察，不會改變 DEM 或等高線的實際海拔值。
- 3D 模型包含水平歸一化比例（X 寬度 10、Z 深度 6）和相對高度，接到 MindAR 時不會自動對齊紙本。
- 教學演示前，務必在 iPad Safari 實測 3D 載入、GLB 輸出、A4 AR 追蹤。開發環境已測試 2D、JSON、ASC 與 PNG，但無法連線外部 Three.js CDN 做最終實機驗證。
